\section{Attack A: Malicious Windows DLL}
\label{sec:attackA}

The first attack, which occurred on July 18, 2025,
infected five \ac{NPM} packages, one of which, eslint-config-prettier, is widely used
with over thirty million weekly downloads \cite{endorlabs2025eslint}.

A maintainer of this package fell victim 
to a phishing email, and the attacker, 
once the account was compromised, published malicious versions of the following packages:
\begin{itemize}
    \item eslint-config-prettier
    \item eslint-plugin-prettier
    \item synckit
    \item @pkgr/core
    \item napi-postinstall
\end{itemize}

The tarball of these malicious versions contains a new file called install.js
and a \ac{DLL} called node-gyp.dll, weighing 1.2 MB.

During the installation or update of one
of these compromised packages,
the install.js script is executed, which invokes rundll32.exe.

The latter loads the node-gyp.dll into memory,
allowing the attacker to perform remote code execution
on Windows systems, enabling for example the installation of 
additional malware.
