\section{Attack A: Malicious Windows DLL}
\label{sec:attackA}

The first attack occurred on July 18, 2025, and compromised five \ac{npm} packages.
Among these, \texttt{eslint-config-prettier} is the most widely used,
with over thirty million weekly downloads~\cite{endorlabs2025eslint};
the remaining infected packages were \texttt{eslint-plugin-prettier}, \texttt{synckit}, 
\texttt{@pkgr/core}, and \texttt{napi-postinstall}.

The tarball of each malicious version contains two new files, 
namely a script called \texttt{install.js} and a \ac{DLL} called \texttt{node-gyp.dll}, weighing 1.2~MB.
During the installation or update of one of these compromised packages, the \texttt{install.js} script is automatically executed;
it checks the operating system of the victim and, upon detecting a Windows environment, 
invokes \texttt{rundll32.exe} to load \texttt{node-gyp.dll} into memory, 
thereby enabling remote code execution and the subsequent installation of additional malware.
